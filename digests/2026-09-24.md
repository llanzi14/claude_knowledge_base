- **Anthropic opens a life-sciences research lab; first result is a Claude-led discovery of a novel enzyme system resembling CRISPR** (2026-09-23) — roughly 950 agents spent 21 hours and 210M tokens sifting ~200,000 reverse-transcriptase (RT) sequences, narrowing to 3,500 candidate systems and then 20 top candidates; one agent flagged an unusual DNA repeat sitting next to an odd RT gene inside bacteriophage genomes. Anthropic named the find **ART** (array-associated reverse transcriptases). Caveat carried by Anthropic itself and outside coverage: ART has **not** been shown to function like CRISPR, and its biological role is still unknown — this is a flagged pattern awaiting wet-lab follow-up, not a confirmed gene-editing tool. Anthropic frames the value as compressing an analysis that would otherwise take an expert scientist weeks to months. No Lanzico action — logged as a capability/research-direction data point.
