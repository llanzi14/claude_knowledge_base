# Digest — 2026-08-06

- **New — Claude Code v2.1.223 shipped today (2026-08-06)**, a fix + small-feature release with **two security fixes**: (1) a crafted Bash command could hide part of itself from the permission-approval dialog (tab/invisible-Unicode padding was a variant of the same bug) — what got shown for approval didn't always match what would actually run; (2) **Workflow scripts could use dynamic `import()` to escape the workflow sandbox** — directly relevant to this KB routine and any other Lanzico automation using the `Workflow` tool. Also fixed: `bypassPermissions` agent mode ignoring the org disable policy; gateway model discovery hiding provider-prefixed Claude model IDs (`vertex_ai/claude-*`, `bedrock/anthropic.claude-*`); resumed sessions hanging/failing on a malformed diagnostics attachment; forked background agents stuck "already resuming"; resume-after-`/cd` returning empty; a rare `git push`-output parsing hang. New: `/review` is now an alias of `/code-review` (`/code-review <level> <pr#>`, `ultra` for deep cloud review, and re-running with no level reuses the last one typed); `/teleport` hint in cloud sessions; marketplace-settings owner wildcards (`"owner/*"`).
