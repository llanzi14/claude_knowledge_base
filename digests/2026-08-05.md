# Digest — 2026-08-05

- **New — Claude Code v2.1.222 shipped** (built 2026-08-05, 02:48 UTC), a fix-only release with **two security fixes**: (1) worktree-isolated sessions and their subagents could run destructive git commands against the **main checkout** instead of staying confined to their own worktree — isolation now applies to file edits and Bash in every session type, not just some; (2) `PreToolUse` auto-allow hooks were **bypassing tool restrictions in background agent tasks** (summaries, compaction, renames) — now correctly enforced. Both are directly relevant to this KB routine and any other Lanzico automation using `Workflow`'s `isolation: 'worktree'` option or background/scheduled Claude Code runs. Also fixed: `/usage-credits` blocking repeat requests after an earlier one was dismissed; startup connectivity checks hanging behind HTTPS proxies; sessions not linking to PRs created after a branch push via the GitHub REST API; org-restricted model aliases dropping to the parent model instead of stepping to the newest allowed one; stream idle timeouts on custom `ANTHROPIC_BASE_URL` gateways; claude.ai connectors falsely flagged as needing re-auth; tool errors not displaying for removed/unavailable MCP servers; `SendMessage` now truncates long summaries instead of rejecting them. Native binary runs without Node.js. [GitHub CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) / [Docs changelog](https://code.claude.com/docs/en/changelog)
