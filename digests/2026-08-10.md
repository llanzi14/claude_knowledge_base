# Digest — 2026-08-10

- **New — Claude Code Auto Mode becomes the DEFAULT for Pro, Max, and Team plans starting 2026-08-14** (announced 2026-08-09) — the biggest Claude Code behavior change since Sonnet 5 launched. Auto mode (opt-in since March 2026) executes tool calls automatically unless a classifier flags them as "irreversible, destructive, or aimed outside your environment" — replacing standing per-call approval prompts as the default experience. Anthropic's safety data: across 1,053 paid testers, the classifier caught **89%** of genuinely dangerous commands vs. **13.6%** caught by humans doing manual per-call approval; independent evaluator Trajectory Labs ran 720 indirect prompt-injection attacks against Fable 5/Opus 5/Sonnet 5 under auto mode — **zero succeeded**. Classifier token overhead is no longer billed for Pro/Max/Team, effective 2026-08-09. Enterprise, Claude API, Bedrock, Vertex, and Foundry stay opt-in for now (admin review window). [Claude blog](https://claude.com/blog/auto-mode-default-in-claude-code) / [TechCrunch](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/) / [the-decoder](https://the-decoder.com/anthropic-sets-claude-code-to-auto-mode-by-default-to-protect-developers-from-bad-approvals/)
