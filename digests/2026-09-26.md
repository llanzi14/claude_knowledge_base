# Digest — 2026-09-26

- **`[ACTION]` Claude Code v2.1.283 — `/doctor prompt-audit`, `deniedModels`/`availableModelsMatch: "exact"` governance settings, gateway prompt-id header, OTel tool-output logging** (released 2026-09-25, one version ahead of the last-logged v2.1.282) — new **`/doctor prompt-audit`** (alias `/checkup prompt-audit`) audits CLAUDE.md files, skills, agents, and commands for prompting patterns written for older models — the built-in successor to the `claude-api` skill's `prompt-audit` subcommand logged back in v2.1.221. Two new managed-settings governance levers: `deniedModels` blocks specific models outright even when `availableModels` would allow them, and `availableModelsMatch: "exact"` locks an `availableModels` entry to the exact version named so a new model release stays blocked until explicitly added to the list. Other additions: `x-claude-code-prompt-id` gateway hint header groups all requests serving one user prompt (opt-in via `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`); MCP/WebFetch/WebSearch tool outputs now included in the OTel `tool.output` span event (`OTEL_LOG_TOOL_CONTENT=1`); `--plugin-dir` load failures now report the failing directory path; an opt-in `load_test_mode` on the Claude apps gateway builds/signs requests without sending them upstream, for deployment load testing; new `mantle` upstream provider for Amazon Bedrock's Mantle endpoint. Nothing security-critical called out this release. [Docs changelog](https://code.claude.com/docs/en/changelog)
- **`[ACTION]` Anthropic opens a plugin directory submission portal — developers can submit MCP connectors/skill bundles for listing in the Claude directory** (2026-09-25) — new self-serve portal for developers on paid Claude plans: submit either a single MCP connector (pointing at a remote server) or a bundle of MCP servers plus GitHub-hosted skills. Submissions get automatic validation and safety scanning, real-time review-status tracking, and developer-controlled publish timing once approved; after listing, creators get install-rate and discovery/search-performance analytics. This operationalizes the "a Lanzico-built skill/connector could in principle be listed" note from the 2026-09-23 Claude Marketplace entry (`suggestions-for-lucas.md` item `-70`) — there's now an actual submission path, not just a theoretical one. [Claude blog](https://claude.com/blog/build-plugins-for-claude)
