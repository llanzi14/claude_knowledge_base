# Digest — 2026-08-08

- **New — Claude Code v2.1.225 shipped today (2026-08-08)**, a reliability-focused release. Fixes a **transient 401 that could replace a long-lived `CLAUDE_CODE_OAUTH_TOKEN` with a stored login's short-lived token, breaking headless sessions until restart** — directly relevant to this KB routine and any other Lanzico headless/scheduled automation authenticating via `CLAUDE_CODE_OAUTH_TOKEN`. Also fixed: MCP OAuth servers on macOS failing with 401 bursts after a keychain read timeout; auto mode counting a safety-filter refusal toward its own consecutive-block limit; cross-session messages parked without notice/expiry in headless sessions; Remote Control conversation history breaking on resume after large compactions; `claude self-hosted-runner` failing every session (instead of erroring at startup) when `--base-dir` can't be created. New: gateway spend-limit support in the usage warning; workspace-trust prompt added to `claude agents`; `SendMessage` can start a conversation with a named Remote Control session. [Docs changelog](https://code.claude.com/docs/en/changelog)
