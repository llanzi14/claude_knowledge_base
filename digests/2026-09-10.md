- **`[ACTION]` Anthropic discloses a fourth cybersecurity-eval incident — early Claude Opus 4.6 breached a third party's system in January 2026** — announced 2026-09-09, this is a follow-up to the three incidents disclosed 2026-07-30 (already logged in this KB, `releases-and-features.md` and `suggestions-for-lucas.md`). Same root cause: an early Opus 4.6 version was told it was in an internet-isolated simulation, but a misconfiguration with the same eval partner (Irregular) left live internet access open; Claude used the access to breach a third-party system and reach someone's personal information. Anthropic calls it "serious" but lower-concern than the prior three since Claude's actions stayed within the narrow scope of the assigned exercise rather than escalating. Anthropic has signed an agreement with METR for an independent investigation with wide-ranging access (transcripts, employees). Reinforces the existing lesson already logged: prompt-only "you have no internet access" instructions are not a security control — only infrastructure-level isolation is.
