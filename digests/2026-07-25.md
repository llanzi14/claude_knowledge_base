# Digest — 2026-07-25

- **Claude Opus 5 launched** (2026-07-24) — Anthropic's fourth model release in under two months (after Fable 5 in June, Sonnet 5 on June 30). New default Opus-tier model in Claude Code (v2.1.219, below). 1M-token context; base API pricing unchanged from Opus 4.8 at **$5/$25 per Mtok** (input/output) — half the price of Fable 5's $10/$50; fast mode available at 2× base price. New **effort dial** setting trades intelligence for speed/cost — across effort levels Anthropic reports ~9pp higher accuracy with a third fewer turns/tool calls and 60% less time than before. Benchmarks: more than doubles Opus 4.8 on **Frontier-Bench v0.1** (coding-from-engineering-drawings eval) and tops Fable 5; **30.2% on ARC-AGI-3** (~3× the next-closest model); beats Fable 5's best **OSWorld 2.0** (computer-use) result at roughly a third of the cost. `[ACTION]` This directly updates the KB's standing model-strategy guidance (previously: "keep production pinned to Opus 4.8, Fable 5 cautiously"). See updated `knowledge-base/releases-and-features.md` and `suggestions-for-lucas.md`. - **Claude Code v2.1.219** (2026-07-24) — ships Opus 5 as the new default Opus model; removes Opus 4.7 from fast-mode support. New `sandbox.network.strictAllowlist` setting silently denies non-allowlisted network hosts for sandboxed commands instead of prompting. New `DirectoryAdded` hook fires after `/add-dir` or the SDK's `register_repo_root` control request mid-session. New `workflowSizeGuideline` settings key configures the Dynamic Workflow size recommendation; Dynamic Workflows now default to "medium" (<15 agents) rather than always suggesting the largest fan-out. Per the changelog, default subagent nesting depth is reported as raised to **3** via `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` — **this appears to partially reverse the "subagents don't nest by default" change logged from v2.1.217 (2026-07-21); treat as unconfirmed until cross-checked against the next official changelog read, since aggregator sourcing on this specific point was inconsistent.** Also: fixes for lost text output during API errors, stale fast-mode status shown in Remote Control clients, and screen-reader issues. `[ACTION]` Update to v2.1.219+; if any Lanzico Workflow relies on the "no nested subagents by default" behavior from v2.1.217, re-verify it after updating.
