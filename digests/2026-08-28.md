# Digest — 2026-08-28

- **`[ACTION]` Claude Cowork gets a built-in browser** (2026-08-27, rolling out this week) — Cowork in Claude Desktop (macOS/Windows/Linux beta) can now open a sandboxed, stateless-by-default browser in a side panel and navigate/read/click/type on real websites — no extension, nothing shared from the user's own browser unless cookies are imported site-by-site. On **Team plans it's on by default** as it rolls out; on **Enterprise it's off by default at launch, turning on by default 2026-09-10** unless disabled; also available in Cowork on web/mobile when the desktop app is online. Distinct from "Claude in Chrome" (browser-extension control, GA since 2026-07-01, already logged) and from Claude Code's separate July 10 desktop browser pane. `[ACTION]` see `suggestions-for-lucas.md` item `-43`. [Claude blog](https://claude.com/blog/cowork-built-in-browser) / [Help Center](https://support.claude.com/en/articles/16607400-use-the-built-in-browser-in-claude-cowork)
- **Anthropic previews Model Hardware Standard (MHS)** (2026-08-27) — a new spec letting Claude operate physical hardware (robot arms, microscopes, liquid handlers, lab/manufacturing equipment) without vendor-specific custom integration work; a vendor publishes an MHS description once and any MHS-aware agent can use it. Built with HHMI; AWS, Danaher, Hugging Face, and Raspberry Pi are early testers; public waitlist now open. Research-preview stage, not a shipped product. No direct Lanzico relevance (no physical-hardware/lab work) — logged for awareness only. [Anthropic](https://www.anthropic.com/news/model-hardware-standard-research-preview) / [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-27/anthropic-tests-new-way-for-claude-to-work-with-robots-and-scientific-lab-tools)
