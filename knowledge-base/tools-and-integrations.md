- **Skill/plugin security scanning (Enterprise beta)** (2026-08-10) — Enterprise plans can enable automatic scanning of third-party skills/plugins at upload or edit time. Claude reviews the contents in an isolated environment (separate from normal sessions) and returns **pass** (installs normally), **warn** (usable behind a caution banner the user must acknowledge — couldn't fully verify, may carry risk), or **fail** (malicious content detected, blocked outright). The scanned copy is deleted after the check; only the result and basic metadata are retained. `[ACTION]` If Lanzico moves to Enterprise or already has admin access, turning this on is a low-cost guardrail against malicious third-party skills/plugins — worth enabling given this KB routine and other automation increasingly pull in external skills.
